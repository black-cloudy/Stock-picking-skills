# 经典美人肩（涨停 → 横盘 → 二次涨停）

## 一、形态理解

**爬山：一开始猛冲一段，中途休息蓄力，然后再次冲顶。**

```
涨停/准涨停（≥9.4%） → 横盘 4~8 天 → 第二次涨停
```

| 爬山 | 股市对应 |
| --- | --- |
| 猛冲一段 | **锚点日**：涨停或准涨停（≥9.4%） |
| 休息蓄力 | **横盘 4~8 天**，不涨不跌 |
| 休息时不会往回走 | **平台重心不下移**（后半段均价 ≥ 前半段 −1%） |
| 休息时动作很小 | **日K小波动**（平均日振幅 ≤ 4%） |
| 休息够了再冲顶 | **第二次涨停** |

> 这是**最严格**的口径：锚点必须是涨停/准涨停。
> 「大涨但没涨停（4%~9.4%）」那种请用 `meirenjian-broad`（广义美人肩）。

---

## 二、判定条件

| 条件 | 取值 | 说明 |
| --- | --- | --- |
| **锚点日涨幅** | **9.4% ~ 10.5%** | 涨停或准涨停（≥9.4% 都算） |
| **横盘天数** | **4 ~ 8 天** | 休息太久说明没劲了 |
| **横盘幅度** | 收盘价在锚点价 **±3.5%** 内 | 平台要窄 |
| **总振幅** | ≤ 15% | 日内影线也不能太大 |
| **平台重心** | 后半段均价 ≥ 前半段 **−1%** | 休息平台不能向下走 |
| **日K波动** | 平均日振幅 **≤ 4%** | 休息时只是小波动 |
| **量能趋势** | 后2日均量 / 前2日均量 **≥ 0.9** | 量能必须撑住 |
| **还没启动** | 横盘期内不得出现涨停 | 否则二次涨停已发生 |
| **市场** | **沪深主板** | 排除创业板/科创板 |
| **其他** | 排除 ST | — |

## 三、执行

```bash
cd /e/StockAgent
python -m stock_agent.screener meirenjian --top 30 --no-auto-relax
```

- 默认参数即为经典口径（锚点 9.4~10.5%），无需额外传参
- **`--no-auto-relax` 很关键**：不加它，CLI 在没命中时会自动放宽横盘天数/震幅，
  选出来的票可能已不满足形态。要看真实结果就加这个参数。
- 想主动放宽时，再加 `--auto` 是默认行为，或显式调 `--max-gap` / `--close-band`

### 可选调整

```bash
# 横盘天数放宽
python -m stock_agent.screener meirenjian --min-gap 3 --max-gap 10

# 震幅放宽
python -m stock_agent.screener meirenjian --close-band 0.05

# 全市场（含创业板/科创板）
python -m stock_agent.screener meirenjian --market all
```

网页看板：`python run.py` → **http://127.0.0.1:8000/mrj**

## 四、实测业绩（不复权真实价格，可逐笔核对）

数据：`.data/raw_bars.db`（新浪不复权）｜30 万本金｜最多 5 只｜收盘选股次日开盘买入｜含手续费
区间：2021-01 ~ 2026-10-16

| 配置 | 期末权益 | 总收益 | 最大回撤 | 交易 | 胜率 | PF |
| --- | --- | --- | --- | --- | --- | --- |
| **本口径（4~8天 ±3.5% 量能≥0.9）** | **483,800** | **+61.3%** | **12.6%** | 177 | 45.8% | **1.46** |
| 相邻（3~8天 ±4%） | 491,632 | +63.9% | 14.4% | 281 | 48.8% | 1.29 |
| 放宽（4~8天 无窄幅约束） | 409,182 | +36.4% | 15.7% | 215 | 42.3% | 1.23 |
| 旧宽口径（3~15天 ±7%） | 94,234 | -68.6% | 69.3% | 718 | 42.8% | 0.78 |

**关键：横盘天数一放宽就亏。** 严格是这套策略唯一的正收益来源。

## 五、实盘纪律

1. 收盘选股 → **次日开盘观察**，别无脑追（次日平均低开 0.4%）
2. **止损：锚点价 × 0.93**，跌破无条件离场
3. 单票 ≤20% 仓位，最多同时 5 只
4. 年均只有约 30 次机会，**没有票就是没有票**，不要硬凑

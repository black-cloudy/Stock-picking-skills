# 趋势票（涨不停不涨停）选股

## 一、形态定义

**趋势票 = 长期横盘 → 均线转多头 → 连续 15~30 天小步上涨（每天 0.5%~5%，从不涨停）→ 加速**

用户提供的两个标准样本：

### 样本 1：002990 盛视科技（2026-03-13 → 2026-04-13，20 个交易日 +32%）

```
2026-03-13   26.22  -2.16%   ┐
2026-03-16   28.85 +10.03%   │ ← 区间内唯一一根涨停（启动日）
2026-03-20   29.00  +1.58%   │
2026-03-27   28.66  -1.10%   │  MA5>MA10>MA20>MA30 全程多头
2026-04-01   30.56  +4.77%   │  MACD 03-20 上穿零轴，红柱全程放大
2026-04-08   32.53  +4.26%   │  最大回撤仅 3.2%
2026-04-13   34.70  +2.36%   ┘ ← 决策日
2026-04-14   38.18 +10.03%   ← 加速
2026-04-15   42.01 +10.03%
（决策日之后 5 日 +40.9%）
```

## 一·补、中间可以有涨停（2026-09 新增，重要修正）

### 用户样本：600802 福建水泥

```
2026-07-23   4.02   ← 趋势起点
2026-08-06   4.46   DIF 上穿零轴
2026-08-13   4.52   DEA 上穿零轴，MA5>MA10>MA20>MA30 成立
2026-09-04   5.21  +9.92%   ← 第 1 次涨停
2026-09-14   5.86  +9.94%   ← 第 2 次涨停
2026-09-16   6.02  +4.51%   （最高 6.30，涨停价 6.34）

38 个交易日 +50%；换手率 13.97%；流通市值仅 27.6 亿
量能持续放大：5.5 万 → 64 万手（约 11 倍）；MACD 柱全程为正并持续放大
```

### ⚠️ 旧版本**完全漏掉了这类票**

旧的两个模板（盛视科技 / 共达电声）是「**平滑型**」趋势；福建水泥是「**放量加速型**」：

| 特征 | 福建水泥 | 盛视科技 | 共达电声 | 差异 |
| --- | --- | --- | --- | --- |
| **`vol_trend` 量能趋势** | **8.62** | 1.74 | 1.15 | **5~7 倍** |
| `ret_std` 日涨幅标准差 | **3.71** | 2.88 | 2.79 | 波动更大 |
| `up_ratio` 上涨占比 | 0.60 | 0.70 | 0.90 | 更低（涨停后会回调） |
| `max_pullback` 最大回撤 | 5.0% | 3.2% | 1.7% | 更深 |
| `close_vs_hh60` 距 60 日高 | 0.956 | 0.989 | 0.978 | 略低 |

所以旧模板下它的距离是 **3.6~4.9（阈值 1.9）→ 永远选不出来**。

### 解决方案：新增福建水泥模板（共 4 个模板）

* `600802 @2026-09-04`（趋势中段 +14%，含 1 次涨停）
* `600802 @2026-09-16`（趋势后段 +31%，含 2 次涨停、量能放大 8.6 倍）

**自检结果**：福建水泥自己排第 1（距离 **1.34**、相似度 **66.5%**）。

### 代价（诚实的取舍）

加入新模板后距离刻度整体右移，同一阈值下筛得更松：

| 距离阈值 | 旧（2 模板） | **新（4 模板）** |
| --- | --- | --- |
| ≤1.50 | 42.9% / 0.2 只 | **41.8% / 0.6 只** |
| **≤1.90** | 43.8% / 1.0 只 | **36.7% / 2.4 只** |
| ≤2.30 | 41.2% / 3.4 只 | **35.5% / 8.2 只** |
| 基准 | 26.8% | 26.8% |

→ 精确率从 43.8% 降到 **39.2%**（仍是基准的 **1.35 倍**），但**换来了对「放量加速型」趋势的覆盖**。
宁可少一点精确率，也不要漏掉一整类形态。

> 想只保留原来的「平滑型」口径：把 `stock_agent/screener/trend.py` 的
> `TREND_TEMPLATE_VECTORS` 删到只剩前 2 个即可（标定表需重新生成）。

## 二、研究方法与**关键诚实结论**

**样本规模**：5481 只股票 × 800 根前复权日线，挖掘出 **253,646 个「稳步上涨状态」样本**（2020-2026）。

> **默认只扫深交所**（`--market sz`）。原因：你提供的两个模板（002990 盛视科技、002655 共达电声）
> **本身就是深交所股票**，用深交所样本单独标定更一致。想要全市场加 `--market all`。

### ⚠️ 先说什么**没用**

我把教科书上的条件全试了一遍，**全部跑输基准**：

| 规则 | 20 日收益 | 上涨率 | vs 基准 |
|---|---|---|---|
| 测试集基准（全部趋势样本） | +2.41% | 53.3% | — |
| ① 上涨占比≥62% + 均线多头 | +2.09% | 51.2% | **-0.32%** |
| ② ① + MA20/MA30 双斜率>0 | +2.07% | 50.7% | -0.34% |
| ③ ② + MACD 零轴上且红柱占比≥0.5 | +2.08% | 50.7% | -0.33% |
| ④ ③ + 平滑（日涨幅 std≤4）+ 回撤≤9% | +2.09% | 50.8% | -0.32% |
| ⑤ ④ + 乖离不过热 | +2.02% | 50.9% | -0.39% |

**原因**：这些条件本质是**追涨**——选出的是"已经涨了一段"的股票，均值回归吃掉了动量。

### ✅ 什么**有用**：与用户样本的相似度

单特征 AUC 都很弱（0.51~0.54），但**「与两个样本的 14 维标准化距离」有单调的预测力**：

| 距离分位 | 样本 | 5 日 | 20 日 | **摸到+15% 概率** |
|---|---|---|---|---|
| 最近 0.1% | 145 | **+3.22%** | +4.22% | **49.7%** |
| 最近 0.3% | 434 | +2.37% | **+5.52%** | 46.8% |
| 最近 0.5% | 723 | +1.51% | +3.67% | 43.3% |
| 最近 1.0% | 1445 | +1.38% | +3.64% | 41.5% |
| 最近 2.0% | 2890 | +1.11% | +3.39% | 40.4% |
| **基准** | 144451 | +0.67% | +2.41% | **26.9%** |

**越像你的两个样本，摸到 +15% 的概率越高（49.7% vs 26.9%，1.85 倍）。**

### 两个样本的共性（这就是"趋势票"的本质）

| 特征 | 盛视科技 | 共达电声 | 说明 |
|---|---|---|---|
| **最大回撤** | **3.2%** | **1.7%** | 全程几乎不回调 ← **最关键** |
| 日涨幅 std | 2.88 | 2.79 | 走势平滑 |
| 上涨占比 | 70% | 90% | 阳线为主 |
| 均线多头 | 是 | 是 | MA5>MA10>MA20>MA30 |
| **MACD 红柱占比** | **100%** | **100%** | 全程红柱 |
| MACD 柱斜率 | +0.46 | +0.97 | 红柱持续放大 |
| 距 60 日高 | -1.1% | -2.2% | 贴着新高走 |
| 涨日量/跌日量 | 1.45 | 1.20 | 涨时放量、跌时缩量 |
| BIAS5 | +4.8% | +9.5% | 短期强势 |
| 60 日涨幅 | +15.9% | +150.2% | **两者差异极大 → 不能用"长期涨幅"筛选** |

> **注意**：共达电声 120 日涨幅 +158%，所以"长期涨太多要避开"这条**不适用于本策略**。
> 这也是为什么我放弃"手工阈值"改用"相似度匹配"。

## 三、⚠️ 收益与风险结构

**口径：仅深交所**（2025-01 ~ 2026-09 时间外样本，393 个交易日，基准 = 全部趋势样本）

| 指标 | 距离≤1.5 | **距离≤1.9（默认）** | 距离≤2.3 | 基准 |
|---|---|---|---|---|
| 每日候选 | ~0.2 只 | **~1.0 只** | ~3.4 只 | 244 只 |
| **摸到 +15% 概率** | 42.9% | **43.8%** | 41.2% | 29.1% |
| 20 日预期收益 | +2.1% | **+2.8%** | +2.7% | +2.0% |
| **20 日预期最大回撤** | -11.2% | **-10.6%** | -10.8% | -8.1% |

**这是一个「高赔率、低胜率」形态**：
- 好的一面：摸到 +15% 的概率比基准高 1.5 倍，20 日收益更高
- 坏的一面：**上涨率反而更低**（48% vs 53%），**预期最大回撤更深**（-10% vs -8%）

### 实盘执行要点

1. **别指望每天都有** —— 历史上大部分日子 0~3 只，空结果是常态。
2. **距离越小越好** —— <1.5 的样本 20 日 +3.7%，但可能几天才出一只。要耐心等。
3. **仓位控制** —— 预期 20 日最大回撤 -10%，比普通趋势股深。不要重仓。
4. **止损** —— 跌破 MA20，或 MACD 柱转绿（hist < 0），趋势结束，走。
5. **止盈** —— 摸到 +15% 后可以考虑减半；如果进入连续涨停则持有到开板。
6. **不是稳赚策略** —— 上涨率只有 48%，靠的是赔率不是胜率。

## 八、停牌股处理（重要）

趋势票常常**在大涨后停牌核查**，而停牌股：

* **不可交易** —— 你买不进也卖不出
* **形态是"冻结"的** —— 最后几根 K 线其实是停牌前留下的，相似度是在旧数据上算的
* **复牌后可能高开也可能补跌** —— 风险不可控

所以脚本**默认排除停牌股**（判断方式：最后一根 K 线的日期是否落后于市场最新交易日）。
想查看它们用 `--include-suspended`，命中记录里会有 `停牌天数` 字段。

> 实测案例：2026-09-14 扫出的唯一命中 `301390 经纬股份`，距离 1.74、相似度 56.4%，
> 形态与模板高度吻合 —— 但它**自 2026-09-10 起停牌**（腾讯/新浪两个数据源都确认），
> 因此被正确排除，当天结果为「无」。

## 九、故障排查

| 现象 | 处理 |
|---|---|
| 结果为空 | **正常**。这类票稀少，平均每日 0~3 只。想放宽用 `--max-distance 2.5` |
| 想确认是否因停牌被排除 | 加 `--include-suspended` 对比；命中里会带 `停牌天数` 字段 |
| 结果太多 | 收紧 `--max-distance` 到 1.5~1.7 |
| 扫描慢 | 先跑 `warmup`；确认 `.data/screener.db` 存在（应约 3 秒） |
| 想看某只票的走势 | `python -m stock_agent.cli kline <代码> -p daily -n 40` |

# 广义美人肩（大涨 → 横盘 → 涨停）

## 一、形态理解

**和经典美人肩是同一套爬山逻辑，只是"第一步"没那么猛。**

```
大涨（4%~9.4%，没封板） → 横盘 3~8 天 → 涨停（首板或二板）
```

| 爬山 | 股市对应 |
| --- | --- |
| 先冲一段（不算猛） | **锚点日**：涨 4%~9.4% 的强势阳线（**没涨停**） |
| 休息蓄力 | **横盘 3~8 天** |
| 休息时不会往回走 | **平台重心不下移**（后半段均价 ≥ 前半段 −1%） |
| 休息时动作很小 | **日K小波动**（平均日振幅 ≤ 4%） |
| 休息够了冲顶 | **涨停**（第一次或第二次都算） |

> **两者的分界：锚点日涨幅 9.4%。**
> ≥9.4% 归「经典美人肩」（`meirenjian-classic`）；4%~9.4% 归本技能。
> 本口径机会更多（信号量约为经典的 120 倍），但波动也大得多。

---

## 二、判定条件

| 条件 | 取值 | 说明 |
| --- | --- | --- |
| **锚点日涨幅** | **4.0% ~ 9.4%** | 强势阳线，但**没封涨停** |
| **横盘天数** | **3 ~ 8 天** | 比经典口径可短 1 天 |
| **横盘幅度** | 收盘价在锚点价 **±4%** 内 | 平台要窄 |
| **总振幅** | ≤ 15% | 日内影线也不能太大 |
| **平台重心** | 后半段均价 ≥ 前半段 **−1%** | 休息平台不能向下走 |
| **日K波动** | 平均日振幅 **≤ 4%** | 休息时只是小波动 |
| **量能趋势** | 后2日均量 / 前2日均量 **≥ 0.9** | 量能必须撑住 |
| **还没启动** | 横盘期内不得出现涨停 | 否则目标涨停已发生 |
| **市场** | **沪深主板** | 排除创业板/科创板 |
| **其他** | 排除 ST | — |

## 三、执行

```bash
cd /e/StockAgent
python -m stock_agent.screener meirenjian --top 30 \
  --anchor-min-gain 4 --anchor-max-gain 9.4 \
  --min-gap 3 --max-gap 8 --close-band 0.04
```

> 因为默认参数是「经典口径」，所以必须显式传上面这几项。

### 可选调整

```bash
# 只要 7% 以上的强势阳线（介于经典与广义之间）
python -m stock_agent.screener meirenjian --anchor-min-gain 7 \
  --anchor-max-gain 9.4 --min-gap 3 --max-gap 8 --close-band 0.04

# 量能要求更严
python -m stock_agent.screener meirenjian --min-vol-trend 1.0 \
  --anchor-min-gain 4 --anchor-max-gain 9.4 --min-gap 3 --max-gap 8 --close-band 0.04
```

## 四、实测业绩（不复权真实价格）

数据：`.data/raw_bars.db`｜30 万本金｜最多 5 只｜收盘选股次日开盘买入｜含手续费
区间：2021-01 ~ 2026-10-16

| 配置 | 期末权益 | 总收益 | 最大回撤 | 交易 | 胜率 | PF |
| --- | --- | --- | --- | --- | --- | --- |
| **本口径（3~8天 ±4% 量能≥0.9）** | **666,088** | **+122.0%** | 28.0% | 741 | 48.3% | 1.16 |
| 量能≥1.0 | 573,876 | +91.3% | 37.7% | 721 | 47.0% | 1.12 |
| 4~8天 + 持有15天 | 512,146 | +70.7% | 35.2% | 549 | 45.4% | 1.14 |
| 窄幅 ±3.5% | 344,510 | +14.8% | 55.4% | 734 | 44.0% | 1.03 |
| 4~9天 | 270,076 | -10.0% | 47.4% | 734 | 43.2% | 0.98 |
| 4~8天 止损9% | 214,717 | -28.4% | 48.1% | 696 | 43.8% | 0.92 |

**⚠️ 这个口径很敏感**：收益最高（+122%）但回撤 28%，且部分相邻参数是负收益。
参数比经典口径脆弱得多 —— 仅建议作为**观察池**，或小仓位试。

## 五、实盘纪律

1. 仓位要比经典口径更小（建议单票 ≤10%）
2. **止损：锚点价 × 0.93**
3. 该口径每天能选出较多票（信号量约经典的 120 倍），**必须按打分排序取前几名**
4. 优先看「60日涨停次数多 + 量能 >1 + 收盘位置高」的票

## 六、和经典口径的对比

| | 经典（meirenjian-classic） | 广义（本技能） |
| --- | --- | --- |
| 锚点涨幅 | 9.4% ~ 10.5% | 4.0% ~ 9.4% |
| 横盘天数 | 4 ~ 8 天 | 3 ~ 8 天 |
| 收盘震幅 | ±3.5% | ±4% |
| 信号量 | 少（五年 351 条） | 多（五年 41,874 条） |
| 回测收益 | +61.3% | +122.0% |
| 最大回撤 | **12.6%** | 28.0% |
| 盈亏比 PF | **1.46** | 1.16 |
| 稳健性 | 高（相邻参数都赚） | 低（部分相邻参数亏） |

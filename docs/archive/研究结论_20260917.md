# 美人肩策略研究结论（2026-09-17 版本）

## 当前默认参数（大道至简 + 三轮优化）
- anchor_min_gain = 9.5%（涨停/准涨停锚点）
- anchor_max_gain = 10.5%（4%~10% 含涨停，10.5 为四舍五入余量）
- close_band = 0.07（横盘收盘 ±7%）
- min_vol_trend = 0.8（量能趋势：后2日均量/前2日均量 ≥ 0.8，不缩量）
- max_range_pct = 0.15（整理期总振幅 ≤ 15%）
- min_gap=3, max_gap=15（横盘 3~15 天）
- market=main（沪深主板，排除创业板/科创板）
- exclude_st=True；avoid_fail=False（六条失败规避默认关闭）

## 五年回测（2021-09-17 ~ 2026-09-17，沪深主板 3181 只）
- 锚点事件 38,964；涨停波 11,677（基准率 30.0%）
- 信号精度 10.7%；事件级精度 28.2%
- 召回 20.3%；漏掉率 79.7%
- 平均每日候选 14.2 只，平均每日命中 1.51 只

分年份信号精度（稳定性）：
2021 10.0% / 2022 10.7% / 2023 10.4% / 2024 9.7% / 2025 10.0% / 2026 12.3%

## 持有到被剔除的最终兑现（用户口径，research/27_holdout.py）
选中 8,316 事件，最终结果：
- 二次涨停（命中）17.4%（涨停距选中日平均 3.9 天，距锚点平均 7.4 天）
- 冲高突破 +7% 未封板 26.0%（涨了但没涨停）
- 跌破横盘下沿 -7% 39.5%（主要亏损来源）
- 横盘超 15 天超时 17.1%
- 方向汇总：向上 43.4% / 向下 39.5% / 不动 17.1%
